# SE Page Alias Test Integration Design

## Goal

Integrate the verified SE page-alias microbenchmark into gem5's formal test
framework while keeping generated build artifacts out of the source boundary.

## Structure

- `src/sim/process.cc` contains the generic alias lifetime fix.
- `tests/test-progs/se/page-alias/` owns the C test source, Makefile, and SE run
  configuration.
- `tests/gem5/se_mode/page_alias/test_page_alias.py` registers the x86 test,
  builds the microbenchmark through a `MakeFixture`, runs `run.py`, and verifies
  the pass marker.
- `tests/test-progs/se/page-alias/.gitignore` excludes the binary, object, and
  static library generated by the Makefile.

## Verification

Run the formal test through gem5's test runner, verify the pass marker, rerun
the two existing lightweight suites, and run `git diff --check`.

## Scope

This integration does not change the already verified runtime behavior or add
new cross-process alias accounting.
